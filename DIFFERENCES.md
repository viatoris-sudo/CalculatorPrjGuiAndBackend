# Отличия от оригинальной реализации Windows Calculator

Данный документ описывает основные отличия этой реализации калькулятора от стандартного калькулятора Windows.

## Краткая сводка

| Категория | Статус | Примечания |
|-----------|--------|------------|
| Базовые арифметические операции (+, -, *, /) | ✅ Реализовано | Полная поддержка |
| Ввод и редактирование (цифры, точка, backspace) | ✅ Реализовано | Полная поддержка |
| Очистка (C, CE) | ✅ Реализовано | Полная поддержка |
| Смена знака (+/-) | ✅ Реализовано | Полная поддержка |
| Процент (%) | ❌ Не реализовано | Кнопка есть, функции нет |
| Обратная величина (1/x) | ❌ Не реализовано | Кнопка есть, функции нет |
| Квадрат (x²) | ❌ Не реализовано | Кнопка есть, функции нет |
| Квадратный корень (√x) | ❌ Не реализовано | Кнопка есть, функции нет |
| Память (M+, M-, MR, MC) | ❌ Не реализовано | Отсутствует |
| Научный режим | ❌ Не реализовано | Отсутствует |
| История вычислений | ❌ Не реализовано | Отсутствует |
| Скобки | ❌ Не реализовано | Отсутствует |

## Реализованные функции

### Базовые арифметические операции
- ✅ **Сложение (+)** - Полностью реализовано
- ✅ **Вычитание (-)** - Полностью реализовано
- ✅ **Умножение (*)** - Полностью реализовано
- ✅ **Деление (/)** - Полностью реализовано с проверкой деления на ноль

### Операции ввода и редактирования
- ✅ **Ввод цифр (0-9)** - Полностью реализовано
- ✅ **Десятичная точка (.)** - Реализовано с защитой от двойного ввода
- ✅ **Смена знака (+/-)** - Полностью реализовано
- ✅ **Backspace (⌫)** - Реализовано для удаления последней цифры
- ✅ **CE (Clear Entry)** - Очищает текущий ввод
- ✅ **C (Clear)** - Полная очистка калькулятора

### Функции отображения
- ✅ **Разделители тысяч** - Автоматическое добавление запятых (1,234,567)
- ✅ **Вспомогательное поле** - Отображение истории операций
- ✅ **Динамический размер шрифта** - Автоматическое уменьшение при длинных числах
- ✅ **Ограничение на 16 символов** - Защита от переполнения

### Особенности логики
- ✅ **Повторное нажатие "="** - Повторяет последнюю операцию
- ✅ **Цепочечные операции** - Поддержка последовательных вычислений
- ✅ **Удаление нулей** - Автоматическое удаление незначащих нулей после точки

## Нереализованные функции

### Расширенные операции
- ❌ **Процент (%)** - Кнопка присутствует, но функция не реализована
  - В enum `operations_t` определена как `PERCENT`
  - В switch-case имеется пустой case для `PERCENT`
  - Не подключена к GUI (строка 153 закомментирована)

- ❌ **Обратная величина (1/x)** - Не реализована
  - Кнопка присутствует в GUI
  - Нет соответствующего enum значения
  - Не подключена к обработчику (строка 157 закомментирована)

- ❌ **Квадрат числа (x²)** - Не реализована
  - Кнопка присутствует в GUI
  - Есть `SQR` в enum, но не используется
  - Не подключена к обработчику (строка 158 закомментирована)

- ❌ **Квадратный корень (√x)** - Не реализована
  - Кнопка присутствует в GUI
  - Есть `SQRT` в enum, но не используется
  - Не подключена к обработчику (строка 159 закомментирована)

### Отсутствующие в Windows Calculator функции
Данная реализация **не** включает следующие функции из полной версии Windows Calculator:
- ❌ Память (M+, M-, MR, MC, MS)
- ❌ Научный режим (sin, cos, tan, log, ln, exp, и т.д.)
- ❌ Программистский режим (битовые операции, системы счисления)
- ❌ История вычислений
- ❌ Конвертер величин
- ❌ Расчет дат
- ❌ Поддержка скобок для сложных выражений

## Отличия в реализации

### Архитектурные особенности

1. **Разделение логики и интерфейса**
   - Калькуляторная логика в отдельных файлах (`CalcLogic.cpp`, `CalcLogic.h`)
   - GUI реализован с использованием Qt6
   - Класс `BackEndWrapper` для связи между GUI и логикой

2. **Формат чисел**
   - Использует запятую (,) как разделитель тысяч
   - Использует точку (.) как десятичный разделитель
   - Windows Calculator использует локаль системы

3. **Обработка строк**
   - Внутреннее представление через `std::string`
   - Функция `add_commas()` для форматирования
   - Функция `remove_str_from_str()` для очистки

4. **Парсинг выражений**
   - Простой парсер в функции `perform_calc()`
   - Обрабатывает строки формата "число операция число ="
   - Не использует стек или дерево выражений

### Ограничения реализации

1. **Только одна операция за раз**
   - Не поддерживает сложные выражения вида "2 + 3 * 4"
   - Каждая операция выполняется сразу при вводе следующей

2. **Ограниченная точность**
   - Использует `double` для вычислений
   - Ограничение на 16 символов ввода
   - Может терять точность при больших числах

3. **Упрощенная обработка ошибок**
   - Только проверка деления на ноль
   - Нет проверки переполнения
   - Нет обработки некорректного ввода

## Особенности пользовательского интерфейса

### Реализовано
- Адаптивный размер окна (360-550 пикселей)
- Автоматическое масштабирование шрифта (от 48 до 60 пикселей)
- Сетка кнопок 4x6
- Два дисплея (основной и вспомогательный)

### Отличия от Windows Calculator
- Упрощенный дизайн без тем оформления
- Нет анимаций
- Фиксированный набор кнопок
- Нет выпадающего меню
- Нет истории операций в боковой панели

## Заключение

Эта реализация представляет собой **упрощенную версию** стандартного калькулятора, фокусирующуюся на базовых арифметических операциях. Основные отличия:

1. **Отсутствие расширенных математических функций** (%, 1/x, x², √x)
2. **Нет функций памяти**
3. **Упрощенная архитектура** с прямым выполнением операций
4. **Минималистичный интерфейс** без дополнительных режимов

Преимущества данной реализации:
- Простота и понятность кода
- Хорошее покрытие тестами
- Чистое разделение логики и GUI
- Адаптивный интерфейс

Реализация подходит для:
- Образовательных целей
- Встраивания в другие приложения
- Базы для расширения функционала
